## Rollout boundary

This task delivers code and a merge-ready PR, not a production rollout or historical repair run. Deploy compatible backend/worker support and finish the bounded canonical-target backfill for each intended current integration/epoch before new clients. The [collector runbook](../deployment/group-telemetry-collector.md#membership-activity-identity-projection) records the exact scope and continuation contract. Unfiltered history stays available; person-filtered reads fail explicitly until their selected range is prepared, with Retry and Clear filters available. Keep new provider recovery capabilities gated until the checkpoint and intended rollout are accepted. Existing lookup/collector behavior must continue to work during an additive rollout or rollback.
