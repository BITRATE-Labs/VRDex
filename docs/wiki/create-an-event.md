# Create a community event

1. Sign in and open **My events**. Choose **Manage [community name] event** for the community hosting the event. Community owners and staff with permission to manage events can use this shortcut.
2. In **Details**, enter the title, start date and time, and time zone. Add a description and location if you have them. In **Lineup**, add performers and set times.
3. Check the details in **Event preview**. To finish later, choose **Save draft**. The event stays private. In **My events**, open **Drafts** and choose **Continue** to pick up where you left off.
4. When you're ready, open **Review** and choose **Publish event**. If you're returning to a saved draft, choose **Save and publish**. VRDex opens the public event page so you can check it and share its link.
